La revisión no reduce derechos ni agrega tratamientos, y rige desde su publicación. **Se mantiene el número de versión a propósito:** una corrección que no cambia derechos ni tratamientos es una revisión, no una versión nueva. Un cambio material sí sube el número y se vuelve a pedir la aceptación.

Los **nombres de archivo de ToS siguen diciendo `v1.2`** a propósito — no se renombraron para no romper las URLs de GitHub Pages ya cargadas en Play Console/App Store.
