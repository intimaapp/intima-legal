## 🚀 Instrucciones de Uso

### Opción 1: GitHub Pages (Recomendado)

1. **Crear repositorio público:**
   ```bash
   git clone https://github.com/[tu-usuario]/intima-legal.git
   cd intima-legal
   ```

2. **Subir archivos .md:**
   ```bash
   git add .
   git commit -m "Política de Privacidad v1.1"
   git push
   ```

3. **Activar GitHub Pages:**
   - Settings → Pages
   - Source: Deploy from a branch
   - Branch: main / root

4. **URLs resultantes:**
   ```
   https://intimaapp.github.io/intima-legal/privacy-policy-es
   https://intimaapp.github.io/intima-legal/privacy-policy-en
   https://intimaapp.github.io/intima-legal/privacy-policy-pt
   ```
